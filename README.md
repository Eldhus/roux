# roux

A Roc platform for hypermedia apps, on
[fourneau](https://github.com/Eldhus/fourneau), a web server in Zig that
faces the internet alone. An app (Roc handlers, typed
[rocstache](https://github.com/Eldhus/rocstache) templates, typed SQL and
migrations, SQLite) builds into one static executable that you copy to a
server and run.

A *roux* (said "roo") is the base every sauce starts from, cooked on the
stove. Part of [Eldhus](https://github.com/Eldhus).

Status: first light. Roc apps run on fourneau, one static executable,
handlers on fibers, with templates, server-sent events and a SQLite
database typed by roux-db (no migrations yet); the milestones and where
it stands are in [TODO.md](TODO.md).

## Build

roux builds against fourneau checked out beside it:

```sh
git clone https://github.com/Eldhus/fourneau ../fourneau
zig build platform                 # the host, as platform/targets/x64musl/libhost.a
zig build tools                    # roux, which builds apps, and roux-db
zig-out/bin/roux build examples/hello.roc && examples/hello   # http://127.0.0.1:8080
zig-out/bin/roux build --dev examples/templates/main.roc      # the fast build, same code
zig-out/bin/roux dev examples/templates/main.roc              # served, rebuilt as you edit
zig build examples                 # regenerate the examples' db/
zig build sqlite-floor             # SQLite alone, timed (vendor/sqlite, sqlite/floor.zig)
zig build db-floor                 # the database workloads without Roc (host/floor.zig)
```

`roux build APP.roc` builds an app: its templates (each
`Page.rocstache` beside it gets a `Page.roc`, its contract and a
one-line `Page.template` making the template's value, and the app gets
`Templates.roc`, the union of them, which the host renders as a response
is sent; `roc glue` lays the
contracts out when one changed; all the templates' bytecode goes into one
object roux writes itself), then roc, then the link, into `APP` beside
`APP.roc` (DESIGN.md, Templates). `--dev` builds with roc `--opt=dev`;
without it, `--opt=speed`. A bare `roc build` makes only an archive now.

`roux dev APP.roc` builds fast, runs the app, and on each save rebuilds
only what changed; the page in the browser reloads itself. A markup
edit is on the screen in milliseconds (the running app rereads the
templates' bytecode: no compiler, no link, no restart), a Roc or
contract change in about 1.2 s on the dragrace site (roc, the link, a
restart; docs/dev-server.md). It also runs roux-db when the app
has `db/`, as `roux build` does.
`--port=N`, `--static=DIR` (the app's static files, which restart it).

Zig 0.17.0 (`.zig-version`) and the Roc nightly in `.roc-version`.
`platform/targets/x64musl/` also needs `crt1.o` and `libc.a` (musl), copied
for now from Roc's test platform at the nightly's commit (TODO).

## Working on it

Read first: [DESIGN.md](DESIGN.md), [TESTING.md](TESTING.md),
[TODO.md](TODO.md), the last entries of
[DIARY.md](DIARY.md) (and fourneau's, for the server). The style and the
notes on Roc and Zig are the eldhus skills (`../eldhus-skill`); read the
roc skill's gotchas before writing Roc. The old basic-webserver fork,
`~/devel/rocstache`, is history: migrate from it only what still makes
sense.

- **Toolchains**: Zig from `.zig-version` and Roc from `.roc-version`,
  installed beside others (`~/.local/share/zig/`,
  `~/.local/share/roc-nightly/`); the `zig` and `roc` on PATH may be
  older, so name the version.
- **A change that needs fourneau** is made in `../fourneau`, tested and
  committed there, then built here; never patched around in the host.
- A platform feature is tested as an example app over a real listener
  (TESTING.md).
