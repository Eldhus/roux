# Security

roux runs untrusted requests through fourneau into Roc handlers.

## Reporting

A security problem in roux: open a private security advisory on GitHub
(Security, Report a vulnerability), not an issue. A problem in the
server underneath belongs to [fourneau](https://github.com/Eldhus/fourneau).

## What it holds

No secrets. An app's own (database files, keys) are the app's.
